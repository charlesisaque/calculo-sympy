# Cálculo 1 - Python

## Descrição

Esta pasta contém implementações em Python de conceitos e técnicas da disciplina de Cálculo 1. O objetivo é utilizar a linguagem Python para resolver problemas matemáticos, realizar cálculos numéricos e explorar conceitos fundamentais do cálculo diferencial e integral.

## Arquivos

### `av1.py`
Arquivo contendo atividades e exercícios práticos da avaliação 1 de Cálculo 1, implementados em Python.

### `calculonv.py`
Módulo com funções e utilitários para cálculos de Cálculo 1, incluindo operações de derivadas, integrais e outras atividades numéricas.

## Tecnologias Utilizadas

- **Python 3.x**: Linguagem de programação principal
- **Bibliotecas**: Possível uso de NumPy, SymPy ou outras bibliotecas científicas

## Como Usar

1. Certifique-se de ter Python instalado em sua máquina
2. Execute os arquivos conforme necessário:
   ```bash
   python av1.py
   python calculonv.py
   ```

## Objetivos

- Aplicar conceitos de Cálculo 1 através de programação
- Resolver problemas matemáticos utilizando métodos numéricos
- Explorar o comportamento de funções, derivadas e integrais
- Visualizar e validar soluções de forma computacional
